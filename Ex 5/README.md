# Ex 5 – Exploring Containerization and Application Deployment with Docker

## Objective

To understand and practice Docker containerization by installing and verifying Docker, managing Docker images and containers, deploying an Nginx web server, practicing Docker commands, creating Dockerfiles, building and running custom Docker images, working with Docker volumes and networking, and deploying a Python web application using Docker.

---

- Nginx

---

## Experiment Description

Docker is a containerization platform used to package applications and their dependencies into portable and isolated containers.

In this experiment, Docker was installed and verified on Windows. Docker images were downloaded and managed, containers were created and controlled, and an Nginx web server was deployed using Docker.

Various Docker commands such as `pull`, `images`, `run`, `ps`, `start`, `stop`, `restart`, `logs`, `rm`, and `rmi` were practiced.

A Dockerfile was also created to build a custom Python application image. Docker volumes were used to demonstrate persistent storage, and Docker networking was explored for communication between containers.

Finally, a simple Python web application was containerized, built into a Docker image, executed inside a container, and accessed through a web browser.

## Docker Commands Used

### 1. Check Docker Version

```powershell
docker --version
```

Displays the installed Docker version.

---

### 2. Check Docker Compose Version

```powershell
docker compose version
```

Displays the installed Docker Compose version.

---

### 3. Display Docker System Information

```powershell
docker info
```

Displays detailed information about the Docker Engine, containers, images, storage, networking, and system configuration.

---

### 4. Pull a Docker Image

```powershell
docker pull ubuntu
```

Downloads the Ubuntu image from Docker Hub.

---

### 5. List Docker Images

```powershell
docker images
```

Displays all Docker images available locally.

---

### 6. Run a Container

```powershell
docker run ubuntu
```

Creates and runs a container from the specified image.

---

### 7. Run an Interactive Container

```powershell
docker run -it ubuntu bash
```

Starts an Ubuntu container in interactive mode.

---

### 8. Create a Named Container

```powershell
docker run -it --name mycontainer ubuntu bash
```

Creates an Ubuntu container with the name `mycontainer`.

---

### 9. List Running Containers

```powershell
docker ps
```

Displays currently running containers.

---

### 10. List All Containers

```powershell
docker ps -a
```

Displays both running and stopped containers.

---

### 11. Start a Container

```powershell
docker start mycontainer
```

Starts a stopped container.

---

### 12. Stop a Container

```powershell
docker stop mycontainer
```

Stops a running container.

---

### 13. Restart a Container

```powershell
docker restart command-practice
```

Stops and starts the specified container again.

---

### 14. View Container Logs

```powershell
docker logs log-practice
```

Displays the output generated by a container.

---

### 15. Remove a Container

```powershell
docker rm mycontainer
```

Removes a stopped container.

---

### 16. Remove a Docker Image

```powershell
docker rmi image-name
```

Removes a Docker image from the local system.

## Docker Image Export and Import

Docker image portability was also demonstrated by exporting images into `.tar` files.

The `docker save` command was used to create Docker image archives.

Example:

```powershell
docker save -o hello-world.tar hello-world:latest
docker save -o ubuntu.tar ubuntu:latest
docker save -o my-python-app.tar my-python-app:latest
docker save -o nginx.tar nginx:latest
```

The saved images can be restored using:

```powershell
docker load -i hello-world.tar
docker load -i ubuntu.tar
docker load -i my-python-app.tar
docker load -i nginx.tar
```

The restored images can be verified using:

```powershell
docker images
```

This demonstrated how Docker images can be exported, transferred, and imported into another Docker environment.
